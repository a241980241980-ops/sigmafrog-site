Sigmafrog 隱私權政策

Privacy Policy · 生效日 Effective: 2026-11-18

1. 適用範圍 · Scope

本政策說明 Sigmafrog（macOS 應用程式及其命令列工具，以下稱「本軟體」）如何處理你的 Google 使用者資料。

This policy explains how Sigmafrog (the macOS app and its command-line tool, “the Software”) handles your Google user data.

2. 存取的資料 · Data accessed

經你授權後，本軟體透過 Google Drive API 存取：你指定的檔案與資料夾的名稱、大小、修改時間、MD5 等中繼資料，以及檔案內容。下載功能只要求唯讀權限；命令列上傳工具僅在你明確執行時，將你指定的本機檔案上傳到你指定的雲端資料夾。

With your authorization, the Software uses the Google Drive API to access metadata (name, size, modified time, MD5) and content of the files and folders you specify. The download feature requests read-only access; the command-line upload tool uploads only the local files you specify to the Drive folder you specify, and only when you run it.

3. 使用方式 · How data is used

資料只用於你要求的動作：列出、下載、驗證或上傳檔案。本軟體不刪除你雲端硬碟中的任何檔案。

Data is used only to perform the actions you request: listing, downloading, verifying or uploading files. The Software does not delete any file in your Google Drive.

4. 儲存與安全 · Storage and security

本軟體完全在你的電腦上執行。登入憑證以 AES-256-GCM 加密存放在你的電腦，加密金鑰存於 macOS 鑰匙圈。下載與上傳紀錄只存在你的電腦。開發者沒有伺服器，不會收到、收集或保存你的任何 Google 資料。

The Software runs entirely on your computer. OAuth tokens are encrypted with AES-256-GCM and stored on your computer, with the key kept in the macOS Keychain. Transfer records stay on your computer. The developer operates no servers and never receives, collects or stores any of your Google data.

5. 分享 · Sharing

本軟體不出售、出租或分享你的 Google 使用者資料給任何第三方，也不用於廣告或訓練人工智慧模型。

The Software does not sell, rent or share your Google user data with any third party, and does not use it for advertising or to train AI models.

6. Google API 使用者資料政策 · Google API Services User Data Policy

本軟體對 Google API 所取得資訊的使用與傳輸，遵守 Google API Services User Data Policy，包括其中的「有限使用」（Limited Use）規定。

Sigmafrog’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. 撤銷與刪除 · Revoking access and deleting data

你可以隨時在 Google 帳戶權限頁面 撤銷本軟體的存取權。在本軟體中中斷連線，或刪除 ~/Library/Application Support/Sigmafrog 資料夾，即可移除電腦上的登入憑證與紀錄。

You can revoke access at any time on your Google Account permissions page. Disconnecting in the app, or deleting the ~/Library/Application Support/Sigmafrog folder, removes the tokens and records from your computer.
